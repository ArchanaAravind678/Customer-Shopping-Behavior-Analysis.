# Customer-Shopping-Behavior-Analysis.


## Project Overview
This project analyzes customer shopping behavior using transactional data from 3,900 purchases across various product categories. The goal is to uncover insights into spending patterns, customer segments, product preferences, and subscription behavior to guide strategic business decisions.

## Dataset Summary
* **Total Records:** 3,900 rows
* **Total Attributes:** 18 columns
* **Key Demographics:** Age, Gender, Location, Subscription Status
* **Key Purchase Details:** Item Purchased, Category, Purchase Amount (USD), Season, Size, Color
* **Behavioral Tracking:** Discount Applied, Promo Code Used, Previous Purchases, Frequency of Purchases, Review Rating, Shipping Type
* **Data Quality Note:** Handled 37 missing values found within the Review Rating column

## Project Workflow

### 1. Data Cleaning & Preprocessing (Python)
Data preparation was executed using Python and the `pandas` library:
* **Missing Data Imputation:** Imputed missing values in the `Review Rating` column using the median rating of each specific product category.
* **Text Formatting:** Renamed all dataset columns into standard `snake_case` format for better documentation.
* **Feature Engineering:** 
  * Binned customer ages into a categorical `age_group` column.
  * Extracted and generated a `purchase_frequency_days` metric.
* **Redundancy Cleanup:** Dropped `promo_code_used` after confirming redundancy with `discount_applied`.
* **Database Pipeline:** Integrated Python with PostgreSQL via SQLAlchemy to seamlessly transition the cleaned dataframe into the database.

### 2. Structured Data Analysis (SQL)
We performed complex business logic queries in PostgreSQL to analyze 10 specific transactional metrics:
1. **Revenue by Gender:** Compared total revenue generated by male vs. female customers.
2. **High-Spending Discount Users:** Isolated buyers using discounts who still spent above the average amount.
3. **Top 5 Products by Rating:** Identified items holding the highest average customer ratings.
4. **Shipping Type Comparison:** Evaluated average transaction values between Standard and Express choices.
5. **Subscription Breakdown:** Compared average spending power and gross revenue between subscribers and non-subscribers.
6. **Discount-Dependent Products:** Flagged the top 5 products with the highest percentage of markdown purchases.
7. **Customer Segmentation:** Classified base into *New*, *Returning*, and *Loyal* tiers.
8. **Category Leaders:** Listed the top 3 most-purchased products within every single product category.
9. **Retention Behavior:** Analyzed if high-frequency buyers (>5 purchases) correlate with active subscriptions.
10. **Age Demographics:** Aggregated gross revenue contributions across mapped generational groups.

### 3. Interactive Visualization (Power BI)
An interactive business intelligence dashboard was compiled to present these metrics visually, monitoring key performance indicators (KPIs) like customer volume (3.9K), average purchase ticket ($59.76), and overall review metrics (3.75).

## Strategic Business Recommendations
* **Boost Subscriptions:** Market tailored milestone perks toward high-value regular shoppers to flip them into active subscriptions.
* **Loyalty Pipelines:** Launch targeted point programs to migrate *New* or *Returning* profiles into the profitable *Loyal* tier.
* **Discount Auditing:** Monitor item markdown frequencies closely to safeguard product margins.
* **Targeted Campaigns:** Direct high-impact ad spends exclusively toward top-tier age brackets and customers frequently opting for express delivery options.
